# OKRs: first semester

**Objective:** Make throwing away event food at Cornell Tech the exception, not the norm.

| Key result | Target | Current | Source |
|---|---|---|---|
| KR1: Meals saved per week | _set after 2 weeks of data_ | – | `mart_weekly_north_star.meals_saved` |
| KR2: Rescue rate (share of posted portions claimed) | _e.g. 60%_ | – | `mart_weekly_north_star.rescue_rate` |
| KR3: Distinct organizers posting per month | _e.g. 10_ | – | `fct_food_posts.organizer_id` |
| KR4: Week-1 retention of new students | _e.g. 40%_ | – | `mart_retention` |

**How to set targets honestly:** run for two weeks, record the baseline, then set a target that's ambitious but based on that baseline. Update the "Current" column from the dashboard each week.
